# Tables

Planned tables for the paper:

1. **Experiment matrix** — all (scenario × strategy × model) conditions
2. **Scenario definitions** — corruption type, count, target column, ground-truth semantics
3. **Correctness results** — repair_recall, correctly/incorrectly/unrepaired per condition
4. **False modification** — originally_clean_values_modified, false_modification_rate
5. **Reliability** — success_rate, recommendation_consistency per condition
6. **Performance** — mean/std execution time per condition
7. **Cost/usage** — token counts where available

Source data: `data/research/results/<experiment_id>/aggregate.csv` and `summary.csv`

No fabricated numbers.
